One word an agent says when it has absolutely no idea what to do next: the voice of a GPS that just drove you into a lake and is now stalling for time.

## Run it

```sh
node main.ts
```

This writes a single word to `/output/entry.txt` (override the output directory with `OUTPUT_DIR`).
